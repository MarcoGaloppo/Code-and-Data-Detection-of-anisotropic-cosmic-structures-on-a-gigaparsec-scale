5. Computation of the Angular Distribution of Pairwise Distances (ADPD)

Script:
    Compute_adpd_python.py

Description
-----------
This script computes the Angular Distribution of Pairwise Distances
(ADPD) for a two-dimensional point distribution inside a circular sample.

The code:

    - reads galaxy positions from points.dat
    - computes pair separations
    - bins pair angles in the interval [0,180) degrees
    - computes the normalized angular probability distribution
    - computes the angular variance sigma_theta^2(r)



Input file
----------

The script expects the file:

    points.dat

containing the projected coordinates:

    x   y


Main parameters
---------------

The following parameters can be modified in the script:

    ANG_BINS   = 720
    DIST_BINS  = 50

where:

    ANG_BINS   = number of angular bins
    DIST_BINS  = number of radial bins


Method
------

1) Pair separations are computed for all galaxy pairs.

2) Pair distances are binned into radial shells.

3) Pair angles are binned in the interval:

       [0,180) degrees

4) For each radial shell, the normalized angular probability
   distribution is computed:

       p_i(r) = n_i(r) / M(r)

where:

       n_i(r) = number of pairs in angular bin i
       M(r)   = total number of pairs in the radial shell

5) The angular variance is then computed as:

       sigma_theta^2(r)
       = (1/Ntheta) * sum_i (p_i - 1/Ntheta)^2


Usage
-----

Run the script with:

    python Compute_adpd_python.py


Output directory
----------------

The script creates the directory:

    ADPD_Output_Python/


Output files
------------

1) angular_dist_bin_*_normalized.dat

   Angular probability distributions for each radial shell.

   Columns:

       theta_deg   p(theta,r)   r_center   p_error   M_pairs


2) pairs_in_shell.dat

   Total number of pairs in each radial shell.

   Columns:

       r_center   M_pairs


3) adpd_angular_variance.dat

   Angular variance as a function of distance.

   Columns:

       r   sigma_theta^2


4) variance_adpd.jpeg

   Plot of the angular variance sigma_theta^2(r).


Purpose
-------

These calculations are used to quantify the angular anisotropy of the
galaxy distribution as a function of scale through the Angular
Distribution of Pairwise Distances (ADPD).

6. ADPD Heatmap Visualization

Script:
    Plot_heatmap.py

Description
-----------
This script generates a two-dimensional heatmap visualization of the
Angular Distribution of Pairwise Distances (ADPD).

The heatmap displays the angular probability distribution:

    p(theta,r)

as a function of:

    theta  = pair orientation angle
    r      = pair separation distance

The script reads the ADPD output files generated by:

    Compute_adpd_python.py

and combines them into a single 2D image.


Input files
-----------

The script expects files of the form:

    angular_dist_bin_1_normalized.dat
    angular_dist_bin_2_normalized.dat
    ...
    angular_dist_bin_N_normalized.dat

Each file corresponds to one radial shell.


Contents of the input files
---------------------------

Each file must contain:

    theta_deg   p(theta,r)   r_center   p_error   M_pairs


Method
------

1) The script reads all radial-shell files.

2) For each shell, it extracts:

       - theta values
       - ADPD probabilities
       - shell radius

3) The angular distributions are combined into a 2D array:

       p(theta,r)

4) The resulting array is plotted as a heatmap using a color scale.


Visualization
-------------

The plot shows:

    x-axis  : theta [degrees]
    y-axis  : r [Mpc/h]
    color   : p(theta,r)

The color scale is automatically rescaled and displayed in scientific
notation.


Main parameters
---------------

The following parameters can be modified:

    n_files
        Number of radial shells to load.

    vmin, vmax
        Minimum and maximum color scale values.


Usage
-----

Run the script with:

    python Plot_heatmap.py


Output file
-----------

The script produces:

    fig_adpd_heatmap.jpeg


Purpose
-------

This figure provides a visual representation of the angular dependence
of pairwise galaxy separations as a function of scale.

Coherent anisotropic structures appear as localized angular excesses
or directional patterns in the heatmap.

8. Poisson Reference Variance Calculation

Script:
    Compute_poisson_statistics.py

Description
-----------
This script generates an ensemble of isotropic Poisson point
distributions with the same geometry and number of objects as the
observational sample, and computes the corresponding angular variance:

    sigma_theta^2(r)

using the Angular Distribution of Pairwise Distances (ADPD).

The script is used to estimate the expected angular variance produced
purely by isotropic random fluctuations.


Input file
----------

The script expects the file:

    points.dat

containing the projected coordinates:

    x   y


Main parameters
---------------

The following parameters can be modified:

    ANG_BINS   = 720
    DIST_BINS  = 50
    N_POISSON  = 100

where:

    ANG_BINS   = number of angular bins
    DIST_BINS  = number of radial bins
    N_POISSON  = number of Poisson realizations


Method
------

1) The script reads the observational sample and determines:

       - the number of galaxies
       - the radius of the circular sample

2) For each Poisson realization:

       - random points are generated uniformly inside the circle
       - the ADPD is computed
       - the angular variance sigma_theta^2(r) is measured

3) The mean and standard deviation of the angular variance are then
   computed over all Poisson realizations.


Usage
-----

Run the script with:

    python Compute_poisson_statistics.py


Output file
-----------

The script produces:

    poisson_variance.dat


Output file format
------------------

The file contains:

    r   sigma_theta^2_mean   sigma_theta^2_std

where:

    r                         = radial separation
    sigma_theta^2_mean        = mean Poisson angular variance
    sigma_theta^2_std         = standard deviation among realizations


Purpose
-------

This calculation provides the isotropic Poisson reference expectation
for the ADPD angular variance.

It is used to compare the observed galaxy anisotropy signal with the
level expected from purely random fluctuations.

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻


9. Bootstrap Estimation of the ADPD Angular Variance

Script:
    Compute_bootstrap_statistics.py

Description
-----------
This script computes bootstrap estimates of the statistical uncertainty
associated with the ADPD angular variance:

    sigma_theta^2(r)

using a weighted Poisson bootstrap procedure.

The script generates multiple bootstrap realizations of the galaxy
sample, computes the ADPD angular variance for each realization, and
estimates the mean and statistical error of the variance as a function
of scale.


Input file
----------

The script expects the file:

    points.dat

containing the projected coordinates:

    x   y


Main parameters
---------------

The following parameters can be modified:

    ANG_BINS   = 720
    DIST_BINS  = 50
    N_BOOT     = 200

where:

    ANG_BINS   = number of angular bins
    DIST_BINS  = number of radial bins
    N_BOOT     = number of bootstrap realizations


Method
------

1) The script computes the ADPD for the full observational sample.

2) For each bootstrap realization:

       - each galaxy is assigned a random Poisson weight
       - weighted pair counts are computed
       - the normalized angular probability distribution is evaluated
       - the angular variance sigma_theta^2(r) is computed

3) The mean and standard deviation of the angular variance are then
   estimated over the full bootstrap ensemble.


Weighted bootstrap
------------------

The bootstrap uses Poisson weights:

    w ~ Poisson(1)

This procedure preserves the geometry of the observational sample while
generating statistically independent realizations.


Usage
-----

Run the script with:

    python Compute_bootstrap_statistics.py


Output directory
----------------

The script creates the directory:

    bootstrap_samples/

containing the individual bootstrap realizations:

    bootstrap_000_variance.dat
    bootstrap_001_variance.dat
    ...


Contents of individual files
----------------------------

Each bootstrap file contains:

    r   sigma_theta^2


Final output file
-----------------

The script produces:

    bootstrap_variance.dat


Output file format
------------------

The file contains:

    r   sigma_theta^2   error

where:

    r                  = radial separation
    sigma_theta^2      = mean bootstrap angular variance
    error              = bootstrap standard deviation


Purpose
-------

This calculation provides the statistical uncertainty associated with
the ADPD angular variance measurements used in the analysis.

The bootstrap errors are used to quantify the robustness of the
observed anisotropy signal as a function of scale.

⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻⸻


10. LCDM Mock Analysis and Consistency Test

Script:
    Compute_LCDM_statistics.py

Description
-----------
This script computes the Angular Distribution of Pairwise Distances
(ADPD) angular variance for an ensemble of ΛCDM mock catalogs and
compares the mock ensemble with the observational data.
The simulation data from which the ΛCDM mock catalogs have been constructed are available at 
https://pages.astro.umd.edu/~diemer/erebos/erebos/snaps/cbol_l2000_n1024/snapdir_100/


The script performs the following tasks:

    1) computes the ADPD angular variance for each ΛCDM mock catalog,
    2) estimates the mean and scatter of the variance over the mock ensemble,
    3) computes the covariance matrix of the mock variances,
    4) compares the observational data with the ΛCDM ensemble using
       a quadratic statistic,
    5) estimates the statistical significance (p-value and sigma level)
       of the observed discrepancy.


Input directories
-----------------

The script expects the directory:

    LCDM_mock_samples/

containing mock catalogs:

    mock_0000.dat
    mock_0001.dat
    ...

Each file must contain:

    x   y

coordinates for one mock realization.


Input observational data
------------------------

The script also requires:

    bootstrap_variance.dat

containing the observational ADPD angular variance and bootstrap errors.


Main parameters
---------------

The following parameters can be modified:

    ANG_BINS   = 720
    DIST_BINS  = 50

where:

    ANG_BINS   = number of angular bins
    DIST_BINS  = number of radial bins


Method
------

For each mock realization:

    - the ADPD is computed,
    - the angular variance sigma_theta^2(r) is evaluated,
    - the result is saved to disk.

The script then computes:

    - the mean ΛCDM angular variance,
    - the standard deviation among mocks,
    - the covariance matrix of the variance estimator.

The observational data are compared to the ΛCDM ensemble through the
quadratic statistic:

    T = (d - m)^T C^{-1} (d - m)

where:

    d = observational variance vector
    m = mean mock variance vector
    C = covariance matrix estimated from mocks

The inverse covariance matrix is corrected using the Hartlap factor.


Mock significance test
----------------------

To estimate the significance of the discrepancy between data and ΛCDM,
the script computes a leave-one-out distribution of the statistic T
using the mock ensemble itself.

The p-value is then estimated as:

    p = fraction of mocks with T_mock >= T_data

The corresponding Gaussian significance is also reported.


Usage
-----

Run the script with:

    python Compute_LCDM_statistics.py


Intermediate output directory
-----------------------------

The script creates:

    LCDM_mock_variance/

containing individual mock variance files:

    mock_0000_variance.dat
    mock_0001_variance.dat
    ...


Intermediate file format
------------------------

Each file contains:

    r   sigma_theta^2


Main output files
-----------------

1)

    LCDM_variance.dat

containing:

    r   sigma_theta^2_mean   sigma_theta^2_std

where:

    sigma_theta^2_mean   = mean ΛCDM variance
    sigma_theta^2_std    = mock-to-mock scatter


2)

    mock_statistics.dat

containing the distribution of the mock quadratic statistic T_mock.


3)

    data_statistic.dat

containing the observational statistic T_data.


4)

    LCDM_consistency_test.txt

containing:

    - number of mocks
    - number of radial bins
    - T_data
    - p-value
    - Gaussian significance


Purpose
-------

This script quantifies whether the observed ADPD angular variance is
statistically consistent with the ΛCDM mock ensemble.

It provides both the mean ΛCDM prediction and the statistical
significance of the discrepancy between observations and simulations.

11. Generation of LCDM Mock Samples from N-body Snapshots

Script:
    Generate_LCDM_mock_samples.py

Description
-----------
This script generates quasi-two-dimensional LCDM mock samples from
cosmological N-body simulation snapshots.

The code reads Gadget-format snapshot files, extracts thin slices of
constant thickness along the z direction, and selects circular projected
regions with the same radius and number of objects as the observational
sample.

The resulting mock catalogues are used as LCDM reference samples for the
ADPD anisotropy analysis.


Input files
-----------

The script expects Gadget-format snapshot files in the current directory
with names of the form:

    snapshot_0100.*

Only the dark matter particle coordinates are used.


Main parameters
---------------

The following parameters can be modified in the script:

    Lbox    = 2000.0
    DZ      = 40.0
    R       = 200.0
    N_target = 27685

    N_circle_per_slice = 20

where:

    Lbox                 = simulation box size
    DZ                   = thickness of each quasi-2D slice
    R                    = radius of the circular projected mock sample
    N_target             = number of particles retained in each mock
    N_circle_per_slice   = number of circular mocks extracted per slice


Method
------

1) The simulation box is recentered around the origin.

2) The box is divided into slices of thickness DZ along the z direction.

3) For each slice, dark matter particles inside the slice are selected.

4) Random circular regions of radius R are extracted in the x-y plane.

5) If a circular region contains at least N_target particles, it is
   randomly subsampled to contain exactly N_target particles.

6) Each mock sample is recentered on the centre of the selected circle.

7) The resulting mock catalogue is written to file.


Usage
-----

Run the script with:

    python Generate_LCDM_mock_samples.py


Output directory
----------------

The script creates the directory:

    LCDM_mock_samples/

containing files of the form:

    mock_0000.dat
    mock_0001.dat
    mock_0002.dat
    ...


Output file format
------------------

Each output file contains three columns:

    x   y   z

where x and y are recentered coordinates within the circular projected
region, and z is the original slice coordinate.


Purpose
-------

These LCDM mock catalogues reproduce the geometry, slice thickness,
sample radius, and number of objects of the observational galaxy sample.
They are used to estimate the expected ADPD signal and its statistical
scatter in the LCDM cosmological model.

12. Distribution of the LCDM Consistency Statistic

Script:
    Plot_LCDM_statistic_distribution.py

Description
-----------
This script plots the distribution of the statistical consistency
estimator computed from the LCDM mock ensemble and compares it with
the value measured from the observational data.

The figure provides a visual representation of the statistical
significance of the observed anisotropy signal relative to the LCDM
expectation.


Input files
-----------

The script expects the files:

    mock_statistics.dat
    data_statistic.dat

generated by:

    Compute_LCDM_statistics.py


Contents of the input files
---------------------------

1) mock_statistics.dat

   Contains the values of the consistency statistic T computed for
   each LCDM mock realization using the leave-one-out procedure.


2) data_statistic.dat

   Contains the value of the same statistic measured from the
   observational data.


Method
------

The script:

1) Loads the distribution of the statistic T obtained from the LCDM
   mock ensemble.

2) Computes the p-value:

       p = fraction of mocks with T_mock >= T_data

3) Converts the p-value into an equivalent Gaussian significance level.

4) Plots:

       - the histogram of T_mock
       - the observational value T_data

The x-axis is shown on a logarithmic scale.


Usage
-----

Run the script with:

    python Plot_LCDM_statistic_distribution.py


Output file
-----------

The script produces:

    anisotropy_statistic_distribution.jpeg


Purpose
-------

This figure is used to quantify the statistical consistency between
the observed galaxy anisotropy signal and the LCDM mock ensemble.

Large values of T_data relative to the mock distribution indicate
that the observed anisotropy signal is unlikely to arise from the
LCDM realizations used in the analysis.

13. Plot of Angular Variance: Data, Poisson, and LCDM

Script:
    Plot_variance_data_poisson_LCDM.py

Description
-----------
This script plots the angular variance sigma_theta^2(r) measured from
the observational data and compares it with the corresponding Poisson
and LCDM reference expectations.

The figure shows the scale dependence of the ADPD angular variance and
is used to assess whether the observed anisotropy exceeds the level
expected from isotropic random fluctuations and from LCDM mock catalogues.


Input files
-----------

The script expects the following files:

    bootstrap_variance.dat
    poisson_variance.dat
    LCDM_variance.dat


Contents of the input files
---------------------------

1) bootstrap_variance.dat

   Angular variance measured from the observational data, with bootstrap
   uncertainties.

   Columns:

       r   sigma_theta^2   error


2) poisson_variance.dat

   Mean angular variance and standard deviation from the Poisson
   reference ensemble.

   Columns:

       r   sigma_theta^2_mean   sigma_theta^2_std


3) LCDM_variance.dat

   Mean angular variance and standard deviation from the LCDM mock
   ensemble.

   Columns:

       r   sigma_theta^2_mean   sigma_theta^2_std


Method
------

The script:

1) Loads the angular variance measured from the data.

2) Loads the Poisson reference expectation.

3) Loads the LCDM mock expectation.

4) Plots:
       - data points with bootstrap error bars
       - Poisson mean with shaded 1-sigma scatter
       - LCDM mean with shaded 1-sigma scatter

The y-axis is shown on a logarithmic scale.


Usage
-----

Run the script with:

    python Plot_variance_data_poisson_LCDM.py


Output file
-----------

The script produces:

    fig_variance_r_data_poisson_LCDM.jpeg


Purpose
-------

This figure provides a direct visual comparison between the observed
ADPD angular variance and the expected behaviour from isotropic Poisson
realizations and LCDM mock catalogues.

A persistent excess of the data above both reference curves indicates
the presence of coherent anisotropic structures beyond the level expected
from random fluctuations or from the LCDM mock ensemble.
